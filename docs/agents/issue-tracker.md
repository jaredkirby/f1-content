# Local implementation records

This project tracks substantial work in `docs/plans/`, as required by its repository
instructions. The current model-selection spec and implementation plan are the
local source of scope, decisions, assignments and verification. Review notes and
runtime evidence belong in ignored `runs/`.

For this task, a skill's instruction to publish a spec means saving it in these
local records. No external issue, comment, pull request or label is created by
the planning workflow. The repository's source-placement rules take precedence
over upstream skills' `.scratch/` examples.

Use status `draft`, `ready-for-agent`, `in-progress`, or `complete` on a local
record. These are local state labels, not assertions about a remote issue tracker.
