# F1 output quality

Shared terms for evidence-first event production and human quality decisions.

## Language

**Local release**: An exact output set that passes the project's technical and
independent editorial, visual and audio checks.
_Avoid_: Human acceptance, published release

**Human acceptance**: The user's explicit approval of the exact output version
they reviewed. A changed version requires its own review.
_Avoid_: Technical pass, model confidence

**Preference**: An explicit human instruction about the desired experience, with
a stated scope such as one output, an event, a format or the project.
_Avoid_: Inferred taste, engagement score

**Model work**: A bounded task with its evidence, observed model configuration,
attempts and generated outputs recorded for later evaluation.
_Avoid_: Model choice, production default

**Model promotion**: A human decision to use an evaluated model route as the
default for a specific capability at the required quality standard.
_Avoid_: Automatic fallback, benchmark win

**Preflight**: A preview of a concrete hosted request and its resource/spending
constraints before model inference is attempted.
_Avoid_: Inference, generated result

**Actual cost**: A measured charge attributed to model work. A provider estimate
or an unavailable measurement is a different kind of evidence.
_Avoid_: Listed rate, estimated cost
